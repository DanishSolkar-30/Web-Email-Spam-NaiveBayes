MODEL INFORMATION

How the detector works

The application uses natural language processing and supervised machine learning to classify email messages.

01

Text Processing

CountVectorizer converts email text into numerical features that the model can understand.

02

Naive Bayes

Multinomial Naive Bayes analyzes the extracted text features and calculates the probability of each class.

03

Classification

The email is classified as either Spam or Not Spam based on the model's predicted probabilities.
