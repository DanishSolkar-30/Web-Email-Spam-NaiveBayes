# 📧 Email Spam Detection using Naive Bayes

A machine learning-powered **Email Spam Detection Web Application** built using **Django**, **Python**, **Scikit-learn**, and **Natural Language Processing (NLP)**. The application uses a **Multinomial Naive Bayes classifier** to analyze email messages and classify them as **Spam** or **Not Spam**, while also displaying prediction probabilities and model confidence.

---

## 📌 Project Overview

Email spam is a common problem where unwanted and potentially harmful messages are sent to users through email. This project aims to automatically identify whether an email message is spam using machine learning and text classification techniques.

The system is trained on a dataset containing legitimate (`ham`) and spam email messages. The email text is converted into numerical features using **CountVectorizer**, and a **Multinomial Naive Bayes** classifier is trained to learn the patterns associated with spam and legitimate messages.

The trained model and vectorizer are saved using **Joblib** and integrated into a Django web application. Users can enter an email message through the web interface and receive an instant prediction along with spam probability, not-spam probability, and model confidence.

## ⚙️ How the System Works

The application follows a complete machine learning pipeline. First, the `spam.csv` dataset is loaded and the required columns are selected. The email labels are converted into numerical values where `ham` represents `0` and `spam` represents `1`. The email messages are then divided into training and testing data. **CountVectorizer** converts the text into numerical feature vectors, which are used to train a **Multinomial Naive Bayes** classifier. The trained model is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix. The model and vectorizer are then saved as `.pkl` files. Django loads these files and processes messages entered by users through the web interface, generating a Spam or Not Spam prediction along with probability scores and confidence.

---

## 🧠 Machine Learning Algorithm

### Multinomial Naive Bayes

The project uses **Multinomial Naive Bayes**, a probabilistic classification algorithm that works particularly well with text classification problems.

It is suitable for spam detection because it can efficiently work with word-frequency-based features generated by `CountVectorizer`.

### Why Naive Bayes?

* Fast training and prediction
* Efficient for large text datasets
* Well suited for NLP classification
* Works effectively with sparse feature matrices
* Simple and interpretable probabilistic approach

---

## 🔤 Text Feature Extraction

### CountVectorizer

The project uses Scikit-learn's `CountVectorizer` to transform email text into numerical features.

For example:

```text
"Congratulations you won a prize"
```

is converted into numerical representations based on the occurrence of words in the dataset.

The vectorizer is trained only on the training data and the same saved vectorizer is used when processing new emails.

## 📊 Model Evaluation

The model is evaluated using:

### Accuracy

Measures the overall percentage of correctly classified emails.

### Precision

Measures how many emails predicted as spam were actually spam.

### Recall

Measures how effectively the model identifies actual spam emails.

### F1-Score

Provides a balance between precision and recall.

### Confusion Matrix

The confusion matrix shows:

* True Negative
* False Positive
* False Negative
* True Positive

The Django dashboard displays these performance metrics directly from the trained model.
